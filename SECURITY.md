# Security

DepCheck parses files you do not trust.
A malformed file that crashes it is a parser bug, reachable by handing someone a file.
Not every crash is exploitable, but the crash does not tell you which it is.

Mail mark.jansen@reactos.org with the file that triggers it, the version from the title bar and your Windows version.
I'll try to answer within a week, fix in the next release.

Wrong dependencies, bad resolution and GUI bugs are normal [issues](https://github.com/learn-more/DepCheck-releases/issues).
