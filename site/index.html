Dependency Checker 

DepCheck shows why a Windows module (exe, dll, ocx) will not load. Drop a file on it and it resolves the imports the way the loader does.


Example result after DepCheck scanning itself.

What it resolves

The real search order:

  • KnownDLLs, from the system directory first.
  • apiset contracts (api-ms-*, ext-ms-*), through the apiset map.
  • SxS / manifest redirection: a Common-Controls 6.0 manifest gives the WinSxS comctl32.dll, not 5.82 from System32.
  • The search path of the analyzed binary's architecture: a 64-bit build reports SysWOW64 dependencies for a 32-bit target, and the other way around.
  • Dependencies of the wrong bitness, reported instead of passed.
  • Forwarded exports, followed to the module that actually implements them.
  • Drivers (.sys), resolved the way the kernel loader does, including System32\drivers.

What it reports

  • Every missing DLL and missing imported function, on the module that imports it.
  • For a missing runtime DLL, the redistributable that ships it.
  • Damaged or oversized import tables, flagged instead of shown as clean.
  • Per file: SHA-256, and whether it carries a Zone.Identifier.
  • The Windows version it ran on, or Wine or ReactOS by name.
  • A clean System32 subtree folded into one line, so the problems stand out.

Download

One executable, nothing to install, Windows XP and later. Either build analyzes 32-bit and 64-bit binaries; pick the one matching your Windows. The ARM64 build, when listed, is experimental and needs Windows 10 or 11 on ARM; x86 and x64 also run there under emulation.

Usage

Drop a file on the window or on the icon; right-click the window for the options below. From a console it writes the tree to stdout:

DepCheck.exe some.dll
DepCheck.exe /depth:2 /imports some.dll
/depth:Nwalk only N levels below the file; 0, the default, is unlimited
/fulllist every System32 module instead of folding clean subtrees
/importslist every imported function, not only the missing ones
/helpshow all options

-full and --full work too. Exit code:

0everything resolved
1a DLL or an imported function is missing (delay-load imports do not count)
2the analysis hit an error
